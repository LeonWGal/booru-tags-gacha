# Booru Tags Gacha

Подтягивает теги из случайного booru-поста в промпт, показывает превью результата и хранит отдельные наборы вкладок для txt2img и img2img.

English: [README.md](./README.md)

## Возможности

- Поддерживает Gelbooru, Rule34, Safebooru, Danbooru, e621 и пользовательский сайт с Gelbooru-DAPI-совместимым API.
- Использует фильтры Include Tags и Exclude Tags при запросе случайного поста.
- Показывает итоговые теги, теги автора, превью изображения и URL поста.
- Даёт действия `Replace Tags` и `Append Tags` для активного промпта.
- Хранит состояние вкладок в `gpr_tabs.json`: 5 вкладок для `txt2img` и 5 вкладок для `img2img`.
- Автоматически сохраняет поля вкладок, включая общий снимок значений при нажатии `Randomize`.
- Поддерживает историю текущей сессии через `Previous` и `Next`.
- Имеет глобальный blacklist и опциональную замену `_` на пробел с исключениями.

## Установка

1. Поместите эту папку в `extensions/` WebUI под именем `booru-tags-gacha`.
2. Запустите или перезапустите WebUI.
3. При первом старте `install.py` устанавливает необходимые Python-зависимости, включая `aiohttp`, `xmltodict` и `furl`.

## Настройка

1. Откройте Settings и найдите секцию `Booru Tags Gacha`.
2. Введите API-данные для сайтов, где они требуются.
3. При необходимости настройте глобальный blacklist и список исключений для замены подчёркиваний.
4. Примените настройки.

## Использование

1. Откройте аккордеон `Booru Tags Gacha` над настройками sampler.
2. Выберите вкладку, затем сайт и значения Include / Exclude.
3. Нажмите `Randomize`, чтобы получить пост и извлечь теги.
4. Используйте `Replace Tags` или `Append Tags`, чтобы вставить результат в текущий промпт.
5. При необходимости используйте `Previous`, `Next`, `Cancel` и `Clear`.

## Примечания

- В `gpr_tabs.json` сохраняются только site, include и exclude для вкладок. Идентификаторы уже показанных постов хранятся только в памяти текущей сессии WebUI.
- Danbooru может возвращать `403` из-за Cloudflare даже при корректных учётных данных.
- Данные e621 опциональны, но без них часть контента может отфильтровываться.
- Пользовательский сайт должен предоставлять Gelbooru-DAPI-совместимый base URL.
- Если после запуска не хватает зависимости, установите её в окружение WebUI и перезапустите интерфейс.

## Кастомизация

Основная настройка выполняется через Settings. Главный скрипт расширения находится в `scripts/BooruTagsGacha.py`, а сохранённое состояние вкладок хранится в `gpr_tabs.json`.
